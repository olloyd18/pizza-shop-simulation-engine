# Pizza Shop Simulation

A Java-based pizza shop simulation I developed as part of my Object-Oriented Programming module at the University of Birmingham.

The program simulates a pizza production system where different buildings produce, process and use resources.

## Features

- Build different entities, including farms, mixers, ovens and restaurants.
- Produce and manage resources such as flour, cheese and pizza.
- Advance the simulation using ticks.
- Use text commands to interact with the simulation.
- Save and load simulation progress.
- View resource information and simple graphs.

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- JUnit for testing

## What I Learned

This project helped me develop my understanding of Java and object-oriented programming, particularly:

- Using classes, inheritance and interfaces.
- Organising code into different packages.
- Working with multiple objects that interact with each other.
- Parsing user commands and managing simulation state.
